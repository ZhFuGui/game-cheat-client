# 项目字体资源

`manifest.json`登记当前字体身份与摘要，TTF原件在同目录。用户提供的仓耳今楷05 W03为项目主字体，保留原始字节；运行不依赖下载目录或系统安装。

Web的`styles/fonts.css`引用此唯一源文件，由Vite输出带摘要的离线资源；原生的`apps/native-host/resources/fonts.rc`把同一文件嵌入宿主和测试程序，由`render/bundled_font`建立私有DirectWrite字体集合。不要在页面中写字体路径，也不要复制另一份源字体到各游戏目录。技术日志和代码等需要等宽排版的位置继续使用独立的等宽字体变量。

新增或替换字体时同步核验清单、Web资源和原生资源；字体变更属于构建与打包输入。直接加载项目字体不安装或修改Windows字体库。
