# PC0.9.2参考弹道运行模型

2026-10-16，revision=`user-model-20261016-v4-configurable-gravity`。用户确认先以相机位置作为弹道起点，继续使用提前量、下坠及等效归零。相机起点是用户选定的参考近似，不是已查实的PUBG原生子弹生成点。以下为已实现模型，区别于[BALLISTIC_AIM_DESIGN.md](BALLISTIC_AIM_DESIGN.md)的更一般设计。

## 输入与时间

Reader提供当前本地人物/当前槽位武器完整生命周期、真实class_name、敌我完整身体世界速度、语义骨点和View。骨点、相机各自保留独立源区间与原点，分别对齐至当前决策时刻，再按100单位/米换SI。相机起点是正式模型选择，所有样本均使用它；不再要求或消费枪口几何及其采样时间，枪口缺失、变化或CLEAR不阻断输出。上游枪口解析仍保留，不改协议或伪造数据。

`CharacterMovement.world.velocity`为cm/s世界轴身体线速度，骑乘/基座贡献已计入，不再相加。合法零向量可用，失败/旧证明/CLEAR不能当0。原生组件字段只保留独立诊断，不假装是完整速度。

四锚点映射要求探测≤3000ms、误差≤25ms、速度与位置采样差≤100ms、年龄加误差≤250ms。不直接相减两机QPC，不用收包/帧开始时间代替字段源时间。当前额外击发延迟δ=0。

相机位置使用View位置字段自己的时间与时钟，按自己的完整身体线速度作短时对齐；不借用Living或枪口时间。旋转采用最近有效View姿态，不预测相机绕身体转动、手动转向或局部动画位移。身体线速度不是相机完整瞬时速度，这些近似属于当前模型范围。相机、自己的完整速度或可靠时间缺失时仍暂停。

## 可配置重力

Aimbot页“重力加速度”以m/s²输入，范围0–100，默认9.8，方向固定竖直向下；0关闭重力下坠。所有枪共用，保存到`ballistics/gravityMetersPerSecondSquared`。原配置没有此项时用9.8；不合法的已存值恢复默认，明确存储的0保留。输入须有限，负数/超范围/空输入/无法转换的文本拒绝并保留上个有效值，不将空文本转换为0；小数不做取整。

Backend将g与资料、归零一起保存到不可变配置快照；输出控制与诊断都显式传入同一g。目标相遇、归零参考和20ms前馈共用该值。重力改变时递增配置代次和输入revision，旧计划撤销，按住时松开再按；重复同值不重置。模型身份包含可往返的g文本及归零距离，避免不同精度共用旧计划。算法面板显示当前配置g和有效解实际使用的g，仍声明用户设定而非游戏实测。

## 飞行与三维相遇

速度键值`(s_i,v_i)`分段线性插值，按用户指定公开参考算法：`ΔT≈Δs×(1/v_start+1/v_end)/2`。负距离键只插值得到0米速度，积分从0开始；末键之后用末速；不足两键时用`T(s)=s/v0`。曲线起点和标称初速不一致时不缩放曲线。编译曲线只在载入时执行。

对齐后的相机C、目标E、目标身体速度V_e和`G=(0,0,-g)`满足：

`B(τ)=C+n·s(τ)+Gτ²/2`，`τ=T(s)`，`B(τ)=E+V_eτ`。

令`R=E-C`，求第一个低飞行时间正根：

`||R+V_e T(s)-G T(s)²/2||-s=0`；随后`n_required=(R+V_eτ-Gτ²/2)/s`。

192个递增距离区间找首个正根括号，至多64次二分到1e-7米，正向代回残差须≤0.002米。资料有射程则优先遵守，否则10km/10秒只作为数值求解界，不能说是游戏寿命。这里将s近似为沿初始方向的推进距离，再独立叠加重力，**不是游戏三维阻力积分器的还原**。

射手速度继承I=0；自己的速度只对齐陈旧相机或推进下一决策起点，不给已出膛子弹加`V_selfτ`。目标恒速平移；未加入加速度、突然转向、骨点局部动画和载具角速度。

## 等效归零

当前相机位置C、单位视线n_sight、归零距离Z。以静止参考点`C+n_sight Z`、同一相机起点和曲线求n_zero；最终：

`n_aim=R(n_zero→n_sight)·n_required`。

R是单位方向间最短三维旋转，不只扣竖直标量，保留高低角。目标解与归零参考使用相同相机起点；不再包含枪口/相机偏移，不还原真实瞄具机构。参考无解也暂停。所有枪共用100/200/300/400/500米，默认100，用户须与游戏设置对应。
