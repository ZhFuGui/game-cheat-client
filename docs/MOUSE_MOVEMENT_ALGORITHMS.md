# 鼠标移动：几何轨迹与速度控制

PC2.8.45，2026-11-19。Aim → 常规将鼠标移动拆成两个独立选择，CS2 Aimbot/Rage 共用；PUBG沿用自己的速度规划并接入相同几何模块。Triggerbot不移动鼠标。

## 当前设置

| 设置 | 选项或范围 | 默认 |
| --- | --- | --- |
| 移动轨迹 mouseTrajectory | linear 直线、bezier 三次贝塞尔曲线 | linear |
| 控制点1沿程 mouseBezierControl1X | 0–100% | 25% |
| 控制点1偏移 mouseBezierControl1Y | -100–100% | 20% |
| 控制点2沿程 mouseBezierControl2X | 0–100% | 75% |
| 控制点2偏移 mouseBezierControl2Y | -100–100% | 20% |
| 速度变化控制 mouseMovementAlgorithm | smooth 平滑加减速、recoil-tracking 后坐优先响应、direct 直接响应 | smooth |

PUBG只开放自己已实现的smooth速度控制。直线保持原运动分支及数值，不额外套用曲线。两个控制点偏移同号可形成弧形，异号可形成S形，均为0时共线。控制点用于塑形，曲线不必经过控制点。UI使用四个百分比参数和即时预览，切回直线不清空参数，各游戏独立保存。

## 分层与数值

游戏仍负责完整资格、目标选择、原生方向/后坐求值、预测、输入计数映射及待反馈账本。几何模块只接收账本处理后的剩余二维计数。以本次路径起点为0，初始终点为D，垂直向量为N=(-Dy,Dx)：

P1 = firstX × D + firstY × N
P2 = secondX × D + secondY × N
B(t) = 3(1-t)²t P1 + 3(1-t)t² P2 + t³ D，0≤t≤1。

百分比在配置适配层除100，纯几何层使用比例。每次准备固定48段的有界弧长表，将速度控制器给出的推进距离映射到曲线位置。dt与限速决定每步走多远，控制点决定走哪条路；不按固定动画时长强行播放。整数输出误差保留在路径累计位置中，最终仍受设备每轴步幅限制。曲线不是新的资格或开枪依据。

动态目标以当前残差和累计输出更新终点，终点控制柄随之平移，起始切线保持。已经实际到达目标时停止旧绕行；路径完成后按当前目标进行末端跟随。旧终点不会在后台排队继续发送。不能将当前速度外推称为未来目标位置已知。

CS2共用Controller将弧长转为一维剩余量，再调用同一个smooth/recoil-tracking/direct时间策略。曲线模式的后坐优先通道沿固定初始弦方向投影，避免切线转动制造伪后坐差分；投影坐标不按360度回绕。P/U的原生数值求值不变。PUBG的TrajectorySmooth使用同一弧长适配，保留既有加减速、jerk和跟踪数值控制。曲线的几何偏移由控制点负责，既有学习模型限速继续适用。

## 状态与提交

BezierPath是只依赖标准库的有界值类型，没有Reader、游戏、串口、UI或存储依赖。应用层mouse_trajectory适配负责JSON和百分比校验，UI继续通过当前游戏的useSettingBinding保存。没有第二条设备输出线程或输入注入入口。

每次提议同时保留速度状态与曲线进度，拒绝发送时共同回滚。CS2曲线模式的smooth同样支持精确重试；默认直线smooth保持原宿主重建规则。PUBG拒绝提议恢复曲线和时间状态。来源、会话、目标、配置或游戏改变仍由既有控制生命周期reset和撤销处理，不能跨目标沿用旧曲线。所有提交前复核和设备预算仍在宿主原链路执行。

## 后座方案与旧配置

Aim常规的“后座方案”只显示原生后坐求值（CS2）或原生发射参考（PUBG），生产设置仅接受aimVersion=v1。不再在该模块选择方向参考或控制变量实验。完整资格与原生E函数保持当前基线。

旧CS2配置的v2/v3/v4或对照ID在读取时归并v1；historical或缺少移动键时，按旧版本解析为显式速度策略（v2→recoil-tracking，v3→direct，其余→smooth）。显式速度ID继续保存。实时写入拒绝旧实验ID和historical。历史纯数学夹具与其说明保留，用于回归核验，不是生产可选入口。

## 后续扩展

新的几何路径应实现独立的剩余弧长/推进状态；新的速度模型只决定沿路径推进距离。两者都必须能够reset和回滚，不能在实时step训练、读文件或申请设备。需要额外输入时扩展公开数值契约，由游戏适配器提供，不能反向读取游戏模型。当前贝塞尔曲线不宣称模拟完整人手行为，合成回归也不代表实战手感结论。
