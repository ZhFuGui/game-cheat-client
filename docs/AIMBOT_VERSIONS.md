# Aimbot 历史算法版本

PC2.8.45起，本文是历史设计及纯数学回归夹具的说明。生产“后座方案”只保留原生求值v1；旧配置与独立几何/速度迁移规则以[MOUSE_MOVEMENT_ALGORITHMS.md](MOUSE_MOVEMENT_ALGORITHMS.md)为准。下面的版本及实验选择器已撤下。

PC2.2.6，2026-10-24。用户要求直接进行可手动比较的实际改动，并提供控制变量实验。本轮不实施生产分段性能采集，不要求Reader增加字段。v1/v2保持原数值方式，新增v3/v4与16个v1单变量组。

PC2.8.25保留这些历史方案，同时新增按游戏保存的`mouseMovementAlgorithm`。CS2缺键使用historical，沿用各版本原运动；用户可独立选择已实现的平滑、后坐差分快速通道或直接量化。此处版本的运动描述均指历史默认，显式选择以界面“当前移动方式”为准。16个单变量组仍固定原平滑基线，不叠加独立移动选择；退出组后恢复保存的选择。详细边界见[鼠标移动策略](MOUSE_MOVEMENT_ALGORITHMS.md)。

## 选择与保存

Aimbot页“算法版本”模块提供标准版本及独立的单变量组选择。CS2提供v1–v4和16个对照组；PUBG当前只有v1，不冒用CS2因素。稳定ID统一保存在该游戏的 `aimVersion`，重开恢复。旧文件缺少此键时使用v1，未知版本拒绝，不静默替换。选择对照组时显示基线v1，不与v2/v3叠加；返回标准版本即可结束对照。

版本保留计算实现。瞄准部位、速度、预计执行延迟、输入换算和学习模型仍使用当前设置，便于同参数比较，不新建多个同游戏工作区。切换先停止旧输出，清理锁定、差分、余量和待反映运动；松开侧键再按，使用新版本。校准期间禁用切换。

## CS2实际字段与版本边界

Build14192使用Source 2的AimPunchServices，不能笼统写成旧版单个 `m_aimPunchAngle`。

| 作用 | Source 2字段或正式Reader量 |
|---|---|
| 服务与所有者 | `C_CSPlayerPawn::m_pAimPunchServices`，核对服务所属Pawn |
| 可预测后坐P | `CCSPlayer_AimPunchServices::m_predictableBaseAngle`、`m_predictableBaseAngleVel`、`m_predictableBaseTick`、`m_predictableBaseTickInterpAmount` |
| 不可预测后坐U | `CCSPlayer_AimPunchServices::m_unpredictableBaseAngle`、`m_unpredictableBaseTick` |
| 本地预测输入 | `C_BasePlayerPawn::v_angle`，对应已核验普通本地source2的eye_basis |
| 网络眼角 | `C_CSPlayerPawn::m_angEyeAngles`，只用于其已核验来源，不替代缺失输入基准 |
| 全局输入角 | `Local.input_view_angles` / `client.dll::dwViewAngles`，仅v4与明确的全局方向对照组将它用于角差参考；v4也用于响应核对 |
| 原生游戏时间 | `AimPunchState.times.simulation`及worldGroup；按Controller/世界时间路线求值，不假设跨批单调 |
| 读取年龄 | `CaptureInterval.started_qpc`、`read_finished_qpc`及可信时钟映射 |
| 目标与速度 | 语义骨点、眼部世界坐标、敌我`C_BaseEntity::m_vecAbsVelocity`、完整人物身份及生命状态 |
| 输入导数 | Reader的`yaw_degrees_per_delta` / `pitch_degrees_per_delta`；实际分支包含`sensitivity`、`m_yaw`、`m_pitch`、`C_BasePlayerPawn::m_flFOVSensitivityAdjust` / `m_flMouseSensitivity` |

所有标准版使用同一个冻结E函数，包含原生基准角/角速度、时间、衰减、积分、插值和缩放，再按当前采样年龄及预计执行延迟外推P/U。单变量组只改变其登记的输入贡献或外推因子，不改E内部定义。没有按用户早期口述公式调整倍率，也没有在外部再乘补偿倍率。默认20ms仍是可修改模型假设。

相机 `CPlayer_CameraServices::m_vecCsViewPunchAngle`、视觉后坐和 `cl_crosshair_recoil` 动画不是额外子弹偏移。未知未来射击/受击和散布不参与预测；现有射击计数不被臆造为瞬时开火状态。字段来源已对照当前Reader的sampling/recoil.cpp、player.cpp、input.cpp和冻结协议。

## v1：固定当前基线

v1对应改动前PC2.2.4：

```text
完整误差 = 目标所需角 - 已核验眼角 - E(P/U)
剩余误差 = 完整误差 - 尚未被采样反映的已接受位移
输出 = 原有比例追赶、加减速、停止距离、小数余量及可选学习模型
```

全部角误差共用原运动曲线。`control/motion/v1.cpp`组合默认参数的`kinematic.cpp`，默认参数由黄金案例固定，实验不能改变其数值。公共来源资格、缺帧恢复和停止规则共享，不恢复旧故障来模拟历史版本。后续新增实现使用新ID和独立版本文件。

## v2：后坐变化快速通道

v2复用v1的状态求值，改变后坐变化到鼠标计数的运动路径：

```text
快速待处理角 += -(当前估计后坐偏移 - 上次有效估计后坐偏移)
快速待处理角按当前完整剩余误差的方向与幅度限制
快速计数 = 在当前速度/每步/XY预算内优先处理快速待处理角
平滑剩余角 = 完整剩余角 - 快速通道负责的待处理角
总计数 = 快速计数 + v1平滑(平滑剩余角，剩余设备预算)
```

快速通道避开追踪增益、起停加速度和微扰，服从当前速度、学习模型速度上限、设备每轴/间隔/XY预算。亚计数速度使用有界预算与小数余量，不能因某步预算小于1而永久不动。

总位移共用已接受账本；平滑先扣除快速部分，避免相同后坐抵消两遍。同一偏移不在每tick重复发送，已知的停火恢复也按变化反向处理，不预测未知下一枪。

仅已核验普通本地预测输入启用快速通道。首次按住、缺组恢复、模拟时间回退或其推进与来源采样明显不连续时重建差分参考；当前帧仍用完整绝对误差作基线跟随，不结束锁定。其他眼角分支或关闭后坐补偿时使用基线运动，运行面板显示实际通道状态。

拒绝的提议回滚差分与速率预算，不遗失/重复计入位移，不重置已经接受的跟随状态。真正松键、明确死亡、会话/身份或版本变化仍清理旧意图；临时缺帧恢复同一目标。

## v3：完整剩余角差直接量化

保留v1的原生眼角、完整P/U、时间/速度预测、映射与已接受位移账本。改变运动生成：

```text
剩余角差 = 当前完整角差 - 预计尚未被采样反映的已接受位移
可用计数 = floor(min(设备单步上限, 上步速率余量 + 当前速度上限 × dt))
输出 = round(clamp(剩余角差 / 有符号每计数角度, ±可用计数))
```

跳过比例追赶、加减速、停止距离和横向微扰；保留当前速度档位、已启用模型的速度上限、每轴/XY预算和半计数/0.01°死区。数值小数残差留在下一次当前角差，不反复累加旧角差。拒绝提议退回本次速率预算。v3是完整运动策略比较，同时改变多个平滑因素，不标成严格单变量。

## v4：v1去掉原生眼角依赖

以`Local.input_view_angles` / `dwViewAngles`替代原生`eye_basis`作为方向参考与响应角；不将原生角置零，也不使用Pawn `v_angle`或网络`m_angEyeAngles`。完整P/U、几何眼部世界位置、v1时间/速度补偿、映射和平滑保留。

```text
方向参考 = 全局输入角 + 原生E(P/U)
完整误差 = 目标所需角 - 方向参考
后续 = v1的账本、计数换算与平滑
```

普通本地角色、全局角、完整P/U和可信时间仍必须有效；缺全局角停止，不回退原生角。假设全局角加P/U能代表世界发射方向，未证明等价于所有父变换、委托或历史眼角路线。数据看板仍可独立展示原生角，不表示v4控制链依赖它。

v4同时改变角差参考、原生眼角资格和响应观察，因此是“移除整个依赖”的策略实验。若只想比较两种角度的数值，使用下面的`compare-global-direction`，它仍要求完整原生眼角并保留v1响应观察。

## 16个单变量对照组

全部以**当前完整v1数据完成资格与目标选择**，再对同一个当前目标只改变登记的一项策略。不能因为关闭P或某速度贡献就放行缺组；不把缺帧当死亡、不重新选另一人。每组保存一个稳定ID，不允许任意叠加开关组合。

| ID | 唯一改动 | 出现差异的条件 |
|---|---|---|
| `compare-global-direction` | 角差基准改为全局输入角，资格/选人/响应仍v1 | 两角真实不同 |
| `compare-no-p` | 实际发射参考不计P，U保留 | 补偿开且P求值非零 |
| `compare-no-p-angle` | 实际E输入的P基准角置零 | 基准角在求值时仍有贡献 |
| `compare-no-p-velocity` | 实际E输入的P基准角速度置零 | 角速度在求值时有贡献 |
| `compare-no-u` | 实际发射参考不计U，P保留 | 补偿开且U求值非零 |
| `compare-no-target-velocity` | 几何只去掉目标速度平移 | 预测开启且目标运动 |
| `compare-no-self-velocity` | 几何只去掉自身速度平移 | 预测开启且自身运动 |
| `compare-no-sample-age` | 外推窗口去掉采样年龄 | 年龄非零且外推改变结果 |
| `compare-no-response-lead` | 外推窗口去掉预计执行延迟 | 延迟非零且外推改变结果 |
| `compare-no-recoil-lead` | P/U只在本批simulation求值 | 后坐随时间变化 |
| `compare-no-pending` | 误差不扣待反馈位移 | 存在预计尚未反映的已接受位移 |
| `compare-no-gain` | 仅取消剩余计数×增益的速度限制 | 比例项正是最紧约束 |
| `compare-no-acceleration` | 速度直接达到本步需求 | 加减速限幅实际生效 |
| `compare-no-braking` | 仅取消停止距离速度限制 | 停止距离项正是最紧约束 |
| `compare-no-variation` | 仅关闭横向微扰 | 开关开启、角差>0.6°且计数距离足够 |
| `compare-no-learned-limits` | 仅不采用模型运动上限 | 启用模型且其限制更紧 |

关闭某贡献不改变原始快照；P角、角速度与U在副本上按同一E求值。采样年龄的**新鲜度资格**与用于**外推的贡献**分别处理；去掉预计执行延迟的外推不改变反馈账本的响应模型。关闭待反馈扣除也不关闭账本记录、超时与响应观察。模型运动上限为一项策略，含其速度/加速度/制动约束；微扰独立，沿用旧实现，可在没有模型时开启。

每组的字段、改变和生效条件直接显示在Aimbot页。相关功能关闭或没有待反馈项时显示无差异提示；已衰减为零、未触及限制或运动停止时无差异是预期现象，不能据此证明该因素无效。共享身份、会话、真实侧键、明确死亡、时钟有效性、设备能力和已核验E的定义不作为可关闭的性能因素。

## 离线比较与手动反馈

v1原15个阶跃案例与PC2.2.4基线JSON逐项一致。另直接运行生产运动模块：60Hz合成后坐阶跃1.375°、4ms读取发布延迟、速度ID3、两版同一固定20ms响应模型：

| 假定物理延迟 | v1达到90% | v2达到90% | v1过冲 | v2过冲 |
|---:|---:|---:|---:|---:|
| 20ms | 58ms | 24ms | 0° | 0° |
| 50ms | 88ms | 54ms | 0.88° | 1.21° |
| 100ms | 138ms | 104ms | 5.69° | 6.02° |

这是运动通道合成阶跃，没有实际盒子或开枪，不是完整枪械后坐波形。90%指第一次穿过阈值，不代表稳定。延迟模型失配时更快纠正也可能增大过冲，因此保留坏案例，不声称v2所有条件都更好。

用户可保持同武器、距离、灵敏度与其他参数，采用v1→一个对照组→v1往返比较，反馈更好/更差/无变化。单变量组固定代码条件，手动游戏场景仍可能变化；不将一次体感当作严格因果证明。无需为本轮新增生产数据采集。

原生检查覆盖20个ID、16组策略恰有一个开关差异、基线目标固定、关闭贡献仍拒绝缺失源、原始状态不变、各模块生效样本、v4无原生眼角、v3预算与拒绝回滚，保留全部既有回归。v1的15组黄金结果与PC2.2.4逐项一致；v1/v2原合成比较保持。真实C++管道验证保存、重开、切回与跨游戏拒绝，不连接设备。旧证据 `R:/cs2/validation/cs2-aim-versions-20261024`，本轮证据 `R:/cs2/validation/cs2-v3-v4-20261024`；实际压枪优势仍由用户手动验收。

## 代码入口

```text
src/games/cs2/control/
├─ policy.hpp / modes.*             # 独立因素、受支持模式与稳定ID
├─ aim_solution.cpp                # 纯计算流水线组合
├─ pipeline/                       # 资格、时序、参考、几何、选人和对照
├─ feedback/pending_motion.hpp     # 待反馈位移账本
└─ motion/
   ├─ types.hpp                    # 有界输入、预算与结果
   ├─ kinematic.*                  # v1默认参数与独立运动因素
   ├─ v1.* / v2.* / v3.*           # 基线、差分快速、完整直达
   └─ controller.hpp               # 分发、重置与提议回滚
packages/shared/src/games/cs2/aimModes.ts         # UI/校验共享模式目录
apps/ui/src/features/aim/common/AlgorithmVersions.tsx  # Aim常规中的共用版本模块
apps/ui/src/games/{cs2,pubg}/AlgorithmVersions.tsx # 实际版本、因素与字段
```

详细模块边界见[CS2计算流水线](CS2_CONTROL_PIPELINE.md)。配置schema仍为1，只允许`aimVersion`缺省，其他必要参数不回填。旧版本不认识新的模式ID；回退整个旧程序包应使用配套数据备份，日常比较直接在新程序中切换。
