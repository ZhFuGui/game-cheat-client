# 游戏配置与用户数据

更新：2026-10-24，PC2.1.1。每款已接入游戏仅保留一份活动配置，侧栏直接选择游戏；没有创建、重命名或管理工作区的产品入口。

## 归属与存储

原生运行时唯一写入业务配置、校准、模型绑定及索引；Electron 唯一写入主题、语言和窗口偏好。默认数据根继续为当前用户的 %LOCALAPPDATA%\Mousebox\。

为了兼容已保存的资产路径与消息身份，内部文件名和 workspaceId 不强制重命名：

~~~text
Mousebox/
├─ web-ui.json                         # 主题、语言、窗口
├─ application.json                    # 全局 DPI / 显卡
├─ workspace-index.json                # schemaVersion 2，单游戏单配置，原子提交点
├─ workspaces/<原有ID>/settings.json    # 每游戏唯一配置；保留既有ID
├─ workspaces/<game-id>-default/        # 新接入游戏自动建立的配置
├─ assets/                             # 采样、模型、报文公共资产
├─ migration-backup/
│  ├─ multigame-v1-<原始来源SHA前16位>/
│  └─ single-game-v2-<原索引SHA前16位>/ # 原v1索引及全部原配置备份
├─ settings.json                       # 历史来源原字节保留
├─ human-motion/
├─ human-speed/
└─ mouse-debug/                        # 历史资产原地保留
~~~

DPI、绘制设备和盒子连接全局共用。Reader 端点/频率、灵敏度、ESP、控制及弹道参数、校准、模型路径/启用/变化关系归游戏；切换不复制模型或重新拟合。公共模型删除仍核对其他游戏引用，包括 Windows 大小写、相对路径和同文件别名。

PUBG 保留既有能力与参数；CS2 使用独立来源、模型、配置和矩阵 ESP，目前不开放瞄准；GTA5 unavailable，不建立可选配置。新增游戏必须完成真实模块装配和验证，标记 available 后，原生自动初始化一份专用配置，选择器自动增加一个游戏选项。

## 无损迁移

没有索引时仍优先读取原 settings.json，其次是 Electron 提供的已选旧配置；迁移前验证备份，保留原始来源、模型、采样和校准。旧 PUBG 参数不作为其他游戏默认值。

v1 多配置索引升级为 v2，policy 为 one-configuration-per-game：

1. 校验原索引、全部原配置和全局设置。
2. 每游戏优先保留当前选中的原ID；该游戏未选中时取原索引第一份。不同配置不混合。
3. 按原索引字节摘要建立备份目录，完整复制原索引和每个原ID的配置并校验SHA。所有原目录、资产和绑定保持原地。
4. 名称元信息统一为正式游戏名，选中项、业务配置及其模型关系不重写。新接入游戏使用自身默认值；若前次中断已留下有效配置文件，验证归属后复用，不覆盖。
5. 最后原子提交 v2 索引。中断可根据相同备份重试，成功后启动幂等，不再次覆盖用户值。

已提交 v2 的重复游戏、损坏文件或缺失必需参数明确报错，不重新默认化。新增向后兼容参数仅通过各 GameConfiguration 显式许可。全局及游戏同时保存仍使用 workspace-transaction.json，失败或提交前中断时回滚为同一份原配置。

## 切换与消息资格

公开动作仅保留 workspace.read、workspace.switch {id}。create / rename 已从共享契约和原生实现删除。内部 Catalog wire schema 仍为1，和存储索引的迁移版本独立。

游戏命令、事件及异步结果继续携带 workspaceId / gameId / epoch；旧代次不能更新新游戏。application 和严格白名单 devices 独立于游戏，不放宽整份 state 的来源检查。日志保留产生时的游戏和代次。

切换先撤销资格、停止采集、恢复光标并清理旧任务/来源/场景，再保存与装配新配置、提交索引和发布新代次。进入切换事务后的清理或提交失败时 active=null、输出保持停止；目标预校验失败可保留原上下文，但桌面仍保持撤销。选择器在撤销状态允许重新选择同一游戏恢复。原生支持同ID重建以实现失败恢复；界面不增加独立重载管理流程。

UI 选择游戏不改变同一 PUBG 会话内既有侧键或人物短暂缺帧规则。当前模型启用关系按原配置恢复，导入或拟合新模型仍不自动启用。

## 验证入口

mousebox-tests --suite application 覆盖单游戏迁移、原参数/资产保留、重复旧配置优先级、备份与重试、自动初始化、失败回滚、全局隔离和代次拒绝。Web 测试和隐藏 Electron 验证覆盖直接选择、能力导航和失败后重新选择；均使用隔离目录，不连接物理设备或采集输入。
