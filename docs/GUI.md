# Mousebox 桌面界面

1.0.0 使用 Electron / React，布局与组件组织参考 DIMO。左侧为概览、ESP、Aimbot、速度学习，底部为日志、设置。顶部是紧凑标题栏和连接状态，底部是运行状态。关闭窗口即退出并停止输出，没有托盘常驻。

ESP 使用左侧设置、右侧 DirectX，Insert 收放左栏。页面保留骨骼关节点和头圈、瞄准范围、预选与锁定高亮。显示设置不会改变目标资格。

设置按常规、固件、游戏输入、校准与诊断、显卡与绘制排序。常规合并主题与语言，支持系统/浅色/深色和中文/English；离线 Geist 字体随发布包提供。

Aimbot 页不需要手动开启，链路和运行会话有效时自动侧键待命；切页不改变待命。停止只终止当前跟随。采集、校准和 F8 桌面测试临时独占输出。其余数据资格和算法保持 PC0.10.0 行为。

速度学习保留原始采集、独立场次、留出验证、拟合、视觉回放、文件导入导出、手动启用与确认删除。没有将每份鼠标原始报告传给 Web；这里只显示位置和计数摘要。

构建、迁移、启动参数及证据见 [WEB_DESKTOP](WEB_DESKTOP.md)。真实游戏操作由用户验收。
