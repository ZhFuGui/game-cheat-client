## 调度与恢复

- 只从当前状态生成候选，不保存故障事件队列。错误字段清空、连接恢复或用户主动断开后，相应错误立即退出候选，不等待下一次轮播，也不播放历史错误或额外“恢复成功”通知。
- 明确连接 error 为红色，degraded 为橙色；connecting 是正在尝试，closed 是关闭/未接入，不从错误文字推测颜色。原生运行时断开后不再显示其残留绿色就绪状态。
- 优先级从高到低：原生断流 100；会话资格/迁移 90；绘制/特征采集错误 60；连接/弹道资料错误 50；数据或设备不完整 40；显卡回退 30。仅显示最高级故障，同级多条轮播；恢复后自动显露剩余有效故障或页面信息。
- 没有故障时，正在采集、统计、拟合、回放、文件处理及当前等待条件固定显示。普通多条信息每 5.2 秒切换，最多 12 条；页面/子页分别保存游标。单条信息不启动轮播计时器。
- 消息以条件 ID 去重。ID 不含报文数、采样时间、错误详情或翻译；重复快照/重试只更新现有详情，不追加条目、不重启动画或重置阅读间隔。
- 只订阅当前页面需要的展示字段；计数与任务进度来自已有有界 DTO，不新增轮询或每秒重建全局状态。日志统计按日志数组身份缓存。
- 主文案与数字详情分开，读屏仅播报主文案；长文本省略且可悬停查看完整内容。窗口按钮保留空间，整条仍可拖动窗口。切换动画 180ms，遵守减少动态效果偏好。

## 验证范围

Web 回归覆盖页面归属、真实零值、故障抢占/同级轮播/恢复、重试去重、计数持续更新不饿死轮播、页面游标、任务固定、故障作用域、中英文、计时器清理及无设备命令。隐藏隔离包验证六页与设置子页、长错误文本在明暗主题及最小尺寸中的布局，以及合成故障恢复；这些不构成前台拖动、跨屏 DPI 或真实设备测试。
