# 目标优先级

PC1.1.6 在 Aimbot 页提供两种未锁定选人模式，配置字段 `values.targetPriority`：

- `0` / `nearest_distance`：人物距离优先，默认。比较相机到所选瞄准部位的三维距离；同距离比较准星角差，再按人物 ID 稳定排序。
- `1` / `closest_crosshair`：准星距离优先。比较所选部位与准星的角差；同角差比较三维距离，再按人物 ID 稳定排序。角差直接使用原有 `angleTo` 的 cone 值，保持动态 FOV 下的几何规则，不混用 ESP 像素尺寸。

两种模式都先执行原有身份、队伍、骨点、几何、角度范围、距离上限及帧配对检查。位置沿用原有数据年龄预测；没有修改弹道、原生方向、控制轨迹或输出资格。

`TargetPolicy` 同时用于 ESP 未锁定预选、运行诊断与实际 `LiveController`。一次按住已锁定时通过完整身份 `requiredIdentity` 过滤，优先级不能把锁转给其他人。暂缺暂停并只恢复同一身份，松开再按才重新选人。运行中更改优先级按现有配置变更机制撤销本次输出并要求松开再按。

配置由 C++ 校验为整数 0 或 1，保存于现有 settings.json。旧文件缺失该字段时补 0，不改变之前的距离优先习惯。它不参与鼠标灵敏度校准签名，不让修改目标排序清空校准或模型。算法来源“候选筛选与优先级”和校准导出 `unlocked_target_priority` 同步当前值。

验证包含相反排序选择、同角/同距稳定平局、近准星但越距/队友/越角排除、真实按住不换人、缺失恢复/新按重选、旧配置默认、新设置持久化与重开、ESP/输出配置一致，以及 Web 下拉选择到 typed IPC 的数值类型。均为隔离测试，实机选人由用户手动验收。
