# ESP视觉尺寸规则

PC2.2.7，2026-10-24，PUBG与CS2共同使用。区分表示世界实体的骨架几何与附加信息，不按固定屏幕像素混用。

## 世界几何

骨点半径、骨架连线粗度、已有头部圆环的描边，都使用当前位置的透视比例。PUBG使用当前相机的`focal / cameraDepth`；CS2从当前矩阵一次预计算屏幕横纵尺度和深度平面，再按每个端点深度求值。不用欧氏距离替代相机深度，不依赖米制换算，也不从缺失单位推断厘米或米。

样式基准优先采用本批已核验的头颈世界跨度。缺头颈时使用已声明骨架边的最长长度×0.25；只有孤立点时用本批点集的世界RMS尺度×0.3，单点退至一个源世界单位的装饰基准。这是装饰尺寸估计，不代表真实骨骼直径、碰撞体或生命状态。参考的世界长度与投影尺度相乘，使等价的源单位变化不影响画面，不会因单纯改变FOV而改用另一套人体大小。

设参考跨度投影为`s` DIP，则：

```text
骨点半径 = 2.5 × s / 16
连线宽度 = 1.5 × s / 16
黑色描边总宽 = 连线宽度 × 7/3
```

没有固定像素下限。距离加倍且相机不变时，骨点、连线与描边都减半；缩小到亚像素后自然减少覆盖率。开镜或画布放大时与骨架位置一起放大，DPI由已有渲染链统一处理，不重复乘。

一根骨架边可使用不同的首尾宽度，按屏幕线段连续渐变；PUBG裁剪后在实际裁剪端点重新计算深度比例。D2D将渐变连线、圆帽、点和空心头环按颜色组成填充几何，描边同样按比例生成，不用固定像素宽度或尺寸分桶。CS2沿用明确的原生边与语义HEAD点，不新增推断连接或头环。

## 附加信息

名字、距离文字、定位角标/点、射线粗度与目标附加标记使用缓和曲线。保留原标记的世界定位；已有按骨架或估计身高形成的框仍保留其几何边界，只调整附加笔画。每个人物输出一个`annotationScale`，后续血量等附加展示也应复用它。

```text
annotationScale = 0.85 + 0.25 × s / (s + 32/3)
```

当`s=16 DIP`时等于1；远处趋近0.85，近处趋近1.10。文字以现有13 DIP字号为基准，约11.05–14.3 DIP；它会随视觉比例缓慢变化，不按世界实体的1/深度快速缩小。文字间距与描边一起变换，不单独保留粗黑边。

文字布局缓存与尺寸变化分离：位置或视觉缩放改变时只设置D2D变换，内容或视口宽度变化时才重新排版。绘制后恢复原变换。状态文字、绘制FPS、观战人数、中心准星和方位环属于界面HUD，保持屏幕尺寸。

## 代码与核验

- `src/render/esp_scale.*`：源单位无关的参考跨度、两类尺寸曲线及矩阵投影尺度。
- `src/games/{pubg,cs2}/presentation/`：各游戏当前几何与投影接入，不跨游戏借用骨点或米制约定。
- `src/render/primitives.hpp`：每端点宽度、每点半径与附加信息尺寸值；不逐帧传到JS。
- `src/render/d2d_esp_geometry.*`：批量渐变填充几何，独立于场景调度和游戏协议。
- `src/render/d2d_scene_painter.cpp`：颜色、裁剪、缓存文字与HUD组合。

原生检查覆盖PUBG/CS2远近、FOV、视口变化、侧向位置、等价源单位、不同端点深度、失效矩阵与亚像素尺寸。CPU Direct2D几何包含性验证圆帽、渐变宽度、交叉边不互相抵消、头环空心和同比例描边，不创建窗口或执行输入。实际观感由用户正常使用时核对。
