# 独立 ESP 页

PC1.0.0，2026-10-16。按用户要求迁移 `G:/pubg-radar` 的原 ESP 页功能，保留本项目 DirectX 的骨骼线、小关节点和头部圆圈；预选及锁定人物采用主题色高亮。React 左栏管理配置，原生右侧画布使用现有 Reader 连接，没有新增远程程序。

2026-10-20，独立显示距离上限和右上角观看本地玩家人数已随PC1.2.4正式发布。PC连接已改为识别现有v5/v6能力，不再要求先配套烧录v6；此前PC1.2.3仅为未安装候选。

PC1.2.5补齐荣都`Neon_Main`的地图单位配置。此前从Radar迁来的官方地图表漏掉荣都；当Reader未单独声明已核验比例时，骨骼仍可投影，但米制距离、估算高度及正数显示距离上限无法使用。现按[官方地图字典](https://github.com/pubg/api-assets/blob/master/dictionaries/telemetry/mapName.json)识别荣都，沿用[官方Location厘米单位](https://documentation.pubg.com/en/telemetry-objects.html#location)的0.01米/单位配置；这是本项目地图配置，不能标成Reader实测比例。Reader显式比例仍优先，未知地图仍不猜单位，也不会继承上一地图的比例。回归覆盖关闭姓名但保留距离、独立世界原点、完整三维50米、49/50米边界、Reader比例优先及切换未知地图。未更改Reader字段或协议。

## 功能对应

| Radar 原入口 | 本项目入口与行为 |
| --- | --- |
| workspace-esp.html / esp-controls | 独立 ESP 页，左侧设置、右侧画布，显示/投影分类，Insert 收起与恢复 |
| marker | 定位角标、定位点、高度估算框 |
| annotations | 名称、相机到实体的三维距离、骨骼、底部中心射线、中心准星，分别开关 |
| people filters | 队友、其他玩家、人机、自己；身份优先，人机队友同时受队友与人机开关控制；另有独立的显示距离上限，默认0表示不限 |
| esp-projection | 16:9、16:10、21:9、4:3、填满区域；水平/垂直 FOV；任意有限正数估算高度，默认1.8米 |
| esp-preferences | 独立 `esp/` 设置，修改即保存，重启恢复，恢复默认只影响 ESP |
| esp-presenter | 可见/输入数量、View/Living源序号、源FOV、单位来源与估算说明；移除页面顶部重复标题/就绪状态和底部裁剪计数，相机缺失原因仅在画布显示 |
| local spectators | 右上角显示观看本地玩家人数；复用已有Local状态，不从场上人物数量推算 |

原默认值一致：角标，名称/距离/中心准星开启，骨骼/射线关闭；队友/其他玩家/人机开启，自己关闭；16:9、水平FOV、1.8米。按用户要求，启用骨骼后继续使用原圆圈样式。实体颜色沿用 Radar 语义：自己白、队友绿、其他玩家红、人机橙；黑色描边保证两种主题下可读。

名称清除控制字符、C1和双向控制字符；空名回退Actor地址或实体ID。角标围绕当前Actor Spatial，不能拿头部或上一帧位置补造。高度框按实体中心、相机右轴与世界Z轴估算，并显示“估算”；不是测量得到的身高、姿态、胶囊体或人体边界。未启用显示距离限制时，未知单位仍显示定位标记，关闭米制距离与高度估算；优先Reader明确核验单位，否则仅在当前核验地图名命中 Radar 的原官方地图表时使用0.01地图配置，明确显示来源。

## 显示距离与观看人数

显示分类的“人物筛选”下新增“显示距离上限”，单位为米，允许有限非负小数，0为不限。设置通过`esp.set / maximumDistanceMeters`交给原生单一写入者保存；旧配置缺失该项时补0，修改后重启恢复，“恢复默认”还原0。该值独立于Aimbot的目标距离，不更改目标优先级、锁定或鼠标输出配置。

原生以相机和Actor分别加上各自世界原点后的三维欧氏距离筛选，使用与距离标签一致的已核验单位来源。边界距离等于上限时可见；超过上限时，在生成骨线、关节点、头圈、定位标记、标签、射线及预选/锁定部位高亮之前跳过整个人物，仅记一次filtered。设置为正数且单位、Actor位置或自身原点缺失时，不猜距离，该人物也隐藏。0保留此前行为，包括缺Actor根位置时仍能绘制独立有效骨骼。中心准星和角度范围圈独立于距离限制。

右上角由`EspStatus`按字段订阅已有`state.spectators`。该值来自正式LocalSpectators的本批计数，并经Reader实例与本地身体生命周期关联核验；不读取被观察对象的计数，不要求Reader增加字段。真实0显示“0 人”；缺失、Local断连、Reader停止或原生桥断连显示“—”，不缓存上一次人数。人数不受显示距离或人物类别筛选影响；Insert隐藏设置栏时仍保留。中英文切换同时更新标签与人数文案。

## 概览预览功能迁移

ESP现在是正式软件唯一的实时投影视图。显示分类新增“瞄准范围”和“目标高亮”，默认开启并保存于esp/aimRange和esp/targetHighlight，恢复默认及重启恢复与其他ESP选项一致。范围来自实际TargetPolicy的15°半角，像素半径为当前投影焦距乘tan(半角)，使用实时FOV、FOV方向、宽高比及实际视口；按视口裁剪，不沿用旧预览固定70像素圆。有效相机到达后，即使人物暂缺也可显示范围；相机无效则清除。

目标选择继续使用原控制资格、距离、部位、时间差和完整身份锁定规则；未改变鼠标控制。预选目标以主题entity色高亮，已按住锁定的目标以selected色高亮，骨线、关节点、头圈、Actor标记、标签和所选部位标记一致更新。完整身份的serial等变化不会继承高亮，人物及显示距离筛选优先，缺目标不会保留旧高亮。隐藏高亮仅影响展示，不改变控制；ESP不复用自瞄距离/年龄限制。

## 数据与绘制

`projectControlFrame`补充本批Spatial位置及自身原点、is_bot的存在性、真实pose_index、单位/地图/展示World与GameState。原瞄准资格与时间补偿不改变，展示用的已验证缓存World不会取得鼠标输出资格。

`EspLayers`在Reader到达时更新独立Living/View；先于UI事件合并处理Reader实例和global epoch切换，清掉另一类别，拒绝旧代次或已退休Reader。World已知不同则暂停显示；不同Level、原点、类别session、采样序号和采样时间不构成ESP拒绝条件。没有时间差/年龄/TTL门槛，未复制自瞄200米等距离限制，没有人数或软件FPS上限。每个相机、Actor和骨点仅加一次自己的原点。最终相机来源与姿态均有效才投影，不从Pawn/身体/旧相机回填。断开/失效清当前层。

队友记忆只保存已核验对局中的人物完整身份和队伍；当前LocalControl/队伍字段短暂缺失可保持筛选。Reader、epoch、World、GameState、地图变化或大厅清记忆；当前不同队伍撤销旧队友。坐标、骨架和is_bot从不由该记忆补回。

`EspProjector`只连接20种人体主干的19种语义边，必须存在真实父索引与有效pose_index，歧义名称/索引不任意选一个，不根据编号猜连线。在相机空间裁剪正深度及四个视锥平面，再进行透视除法；实体中心在视野外不能删除仍穿过视野的骨线。近裁剪余量只取数值精度，没有世界距离阈值。View更新缓存并复用Living骨架连接关系。

Direct3D11/Direct2D/DirectWrite使用独立工作线程、最新场景邮箱、数据通知和`Present(0, DO_NOT_WAIT)`。骨架/角标/射线按人物颜色批量提交，文字布局仅在文本或视口宽度改变时重建，删除离开视野的标签缓存；正常绘制不读回GPU或跨桥传像素。隐藏页面、最小化或模态对话框时停止GPU工作，恢复后画最新数据。10Hz状态展示不驱动画面。

设置栏与画布并排，画布大小由当前剩余客户区域决定；模态提示和选择框显示期间隐藏原生子窗口，关闭最后一个遮挡后恢复。Insert仅在ESP页有效，编辑文字时不拦截，不注册系统全局热键，也不进入鼠标报文处理。

## 入口与验证

正式软件左侧选择ESP；`--esp`可直接打开此页。Reader连接复用概览入口；页面设置不会连接串口或开始采集。该页面是独立投影视图，沿用 Radar 原页面用途。

当前 `mousebox-tests --suite render` 覆盖165项纯投影/选项/身份/裁剪等模型检查；显式 `--suite window` 验证隐藏原生窗口和 DirectX。Web测试覆盖配置、Insert编辑保护、左栏、遮挡、双主题与语言；桌面隐藏验收覆盖真实跨进程 HWND。新增回归覆盖距离边界、完整3D距离、独立原点、单位来源、未知距离、全人物图形剔除、0与小数的保存恢复、侧键控制配置隔离，以及人数0/缺失/断线/恢复和翻译。旧版结果仍只在其历史范围内有效。所有合成和隔离结果均不代表游戏内实时吞吐或鼠标手感已验收。
