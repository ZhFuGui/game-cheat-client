# CS2 Triggerbot 内缩与执行时刻预测

PC2.8.50 起从 Aim → 常规读取共享的 `cs2HitboxInsetPercent`，范围 0–90%，新配置默认 10%。判断先确定实际首先命中的原尺寸人物和部位，再要求射线进入该 Hitbox 按资源尺寸收缩后的区域。0% 采用原始几何，仍执行时序核验。

Triggerbot使用既有时钟映射估计采样区间中点年龄和不确定度，沿用自身cs2TriggerMaxAgeMs准入；Aim 常规的 cs2ResponseMs 表示发出输出指令至输入生效的估计耗时，默认 20 ms。PC2.8.43 在 Triggerbot 判断条件增加「自修正时间差」cs2TriggerTimeOffsetMs，范围 -100 至 100 ms，整数，默认 0 并按游戏保存。命中预测时长为 max(0, 采样年龄 + 预计执行延迟 + 自修正时间差)。负值缩短外推，正值延长。0 ms 预测使用本批姿态。修正值只作用于命中预测，逐目标反应时间继续使用真实采样时间。双方完整速度平移视点与命中体，骨骼旋转/缩放沿用本批姿态；已知P/U状态用既有原生求值推进，不预测新射击冲量、未知手动转向、加速度或骨骼动画。缺速度/时钟/预测状态不补0，不把确定性预测称为命中概率或服务器保证。

DetectionScene按不可变帧缓存几何；同一帧随着等待时间增加仍重新计算预测，不复用旧的命中结论。准备几何耗时加入一次重算，正式提交前重新算时间与射线，所选人物变更、离开内缩体积或状态过期均不提交旧点击。原生资源/协议/字段资格仍保持；Rage调用detect的默认参数为零预测/零内缩，维持其原有求值路径。

自 PC2.8.44 起，StaticCover 按来源与地图身份后台加载场景。当前预测射线和正式提交直接复用已加载的静态场景。开启掩体的反应时间子项时，ReactionMonitor 另按本批实际骨点记录可见时间。最新扫描未完成时，只可对相邻观察的同一已知骨点做本帧复核。

前台检测由Aim常规cs2CheckForeground控制，默认开启，只对原有Triggerbot/Rage前台条件生效。关闭不证明远端游戏处于前台，其他数据、会话和设备条件仍保留。Reader和固件无需修改。
