# Aimbot计算来源说明

PC1.1.0，2026-10-16。Aimbot页的“算法来源与原理”与跟随设置并列，可搜索、筛选、展开、复制和重新加载弹道资料；支持浅色/深色及中文/英文。`--aimbot-algorithm`可直接打开。

## 实际参与与模型约定

生产链已接入独立源时间对齐、三维飞行相遇、下坠、等效归零反解和原鼠标控制。输入缺失、时钟不可靠、资料不匹配或无解时暂停，不退回未补偿输出；按原规则保留本次目标。当前源码消费0B3C4F19 Local契约；196947A2属于此前版本。协议配对部署和只读链路验收以本轮项目记忆为准，离线通过不代表游戏效果。

`CurrentBallisticsAssumptions`保存用户确认的相机起点、基础同向+等效归零角、公开曲线求积、射手速度继承0、用户可设置的向下重力（默认9.8 m/s²）；revision=`user-model-20261016-v4-configurable-gravity`，`liveBallisticsIntegrated=true`。全部仍是用户选定近似，不是Reader测得的游戏规则。相机起点同时用于目标飞行解和归零参考，枪口位置/方向/时间均不参与；相机和完整速度仍严格核验。归零100/200/300/400/500米、默认100，所有枪共用。Aimbot页重力范围0–100 m/s²，0关闭重力下坠，自动持久化；相遇、归零参考与20ms前馈共用此值。说明里的G=(0,0,−g)和摘要按配置更新，不再固定写9.8。报告`assumptions.gravity_m_per_s2`为当前设置、`gravity_source=user_setting`，有效`ballistics.gravity_m_per_s2`来自真实解算诊断。具体公式见[BALLISTIC_RUNTIME.md](BALLISTIC_RUNTIME.md)。

EXE旁`data/weapons/profiles.json`可完整验证后原子重新加载，失败保留旧有效资料，相同revision不重复重置。实时按当前武器真实class_name精确匹配；资料库预留物品ID匹配，当前投影未填充。保留reference_only来源，未知模型、无弹速或冲突别名拒绝输出。

## 说明入口与维护

`src/application/diagnostics/aim_algorithm.cpp`的`describeAimAlgorithm`从同一次Backend快照、当前诊断目标与本机时刻生成说明，不连接Reader、不查询网络、不下发位移、不启用模型。界面打开来源面板时订阅，普通状态最多10Hz；这些展示更新不驱动ESP或控制节拍。

| 分组 | 项目数 | 内容 |
| --- | --- | --- |
| 弹道约定与接入状态 | 8 | 同向、曲线求积、继承、重力、归零、相机起点、枪械资料、飞行提前量 |
| 数据、目标与三维角度 | 9 | 来源配对、坐标/原点/距离、部位、筛选、锁定、采样差、速度、时间补偿、角度 |
| 输入换算与鼠标控制 | 11 | 换算、FOV/灵敏度/DPI、分阶段速度上限、轨迹、前馈、模型、微扰、源时间反馈、角度外扰与未证射击数据、稳定区、触发停止 |
| 当前未参与的计算 | 2 | 加速度/局部动画、遮挡/命中/开火 |

每项都有稳定ID、当前值、来源、原理和状态。`wired`表示该项在链路内，`conditional`表示条件满足时可用，`agreed`和`missing`表示尚未接入，`excluded`表示当前不参与。动态`available`是最近诊断快照的可用性，不是某条已发指令的执行回执；界面明确说明“已接入”不等于此刻正在输出。

实际数值应优先从策略函数、当前配置、校准、目标与`predictPosition`结果读取；说明文字中的公式与固定约束必须随对应控制代码一起维护，新增参与项同时登记稳定ID、翻译和状态。分组只在内容/语言变化时重建，100ms更新不重建整组或清掉展开状态。复制操作只在用户点击时写剪贴板，复制不受当前搜索/筛选影响。

实时只用Reader独立证明的完整身体世界速度，骑乘/基座贡献已计入，不再相加。组件速度只保留诊断；旧录制组件估算不授予弹道资格。数据年龄和子弹飞行时间分两次明确处理，各只一次；虚拟视线点不再经过旧预测/差分。20ms前馈来自共同推进目标与相机后的重新求解。面板显示实际模型revision、资料路径、枪型、飞行时间、下坠、相机起点XYZ及独立源年龄、参考归零角和数值残差；无有效解时飞时/下坠缺失，不假显示为0。稳定ID`origin`替代旧`muzzle`条目；报告显式`trajectory_origin=reader_camera`、`muzzle_geometry_used=false`，移除`muzzle_age_ms`。

## 本地验证边界

PC1.1.0增加`rotation_sample`只读时间诊断与`angular_feedback`活动控制诊断，区分数据年龄、暂估20ms响应、残差、预测量和ACK。约束及150场无设备回归见[角度反馈](ANGULAR_FEEDBACK.md)。原始ControlRotation候选未接入，相机外扰不冒称纯后坐角。

当前原生应用测试覆盖30项唯一ID、来源、原理、相机起点、g0、射手速度继承0和非损失代次字符串；Web测试覆盖来源面板、搜索、订阅、动态英文及参数表单。后台管道互验使用真实原生进程检查全部30项，不连接设备。它们不证明真实Reader频率、游戏命中率、手感或1000Hz。历史版本的独立结果保存在项目记忆与隔离证据中。
